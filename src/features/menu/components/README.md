# Thư mục: src/features/menu/components/

## Danh sách các component JSX:
- 📄 `AdminMenuHeader.jsx`: Thanh tiêu đề đỉnh trang quản lý thực đơn kèm trạng thái KDS Realtime.
- 📄 `MenuSummaryControlBar.jsx`: Thanh công cụ thống kê nhanh số lượng, ô tìm kiếm và nút Thêm Món Mới.
- 📄 `CategoryFilterRibbon.jsx`: Dải băng chọn danh mục món dạng pill cuộn ngang kèm số lượng.
- 📄 `MenuItemRow.jsx`: Hàng hiển thị chi tiết món ăn (ảnh, tên, giá, mô tả, công tắc On/Off, nút Sửa/Xóa).
- 📄 `MenuItemModal.jsx`: Hộp thoại thêm mới hoặc chỉnh sửa món ăn đầy đủ các trường dữ liệu.
- 📄 `KdsToastNotification.jsx`: Toast thông báo realtime xuất hiện góc màn hình khi cập nhật thực đơn.
- 📄 `MenuPagination.jsx`: Thanh điều hướng phân trang danh sách món ăn.
