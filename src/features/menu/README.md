# Module: src/features/menu/

## 1. Mục đích
Quản lý toàn bộ thực đơn món ăn, danh mục phân loại, bảng giá và trạng thái bật/tắt phục vụ KDS thời gian thực cho nhà hàng lẩu Hỏa Diệm Các.

## 2. Cấu trúc thư mục:
- 📁 `components/`: Chứa các thành phần giao diện bóc tách (Header, ControlBar, CategoryRibbon, ItemRow, Modal, Toast, Pagination).
- 📁 `data/`: Chứa dữ liệu mock thực đơn và phân loại danh mục (`mockMenuItems.js`).
- 📄 `index.js`: Barrel export module menu.
