# Thư mục: public/

## 1. Mục đích
Lưu trữ các tài nguyên tĩnh được nạp trực tiếp qua đường dẫn gốc mà không cần Vite biên dịch hay băm tên file (hash).

## 2. Danh sách các file cần có:
- 📄 `favicon.svg`: Biểu tượng logo thương hiệu nhà hàng trên tab trình duyệt.
- 📄 `sounds/ting-ting.mp3`: File âm thanh chuông báo order mới phát ra tại màn hình trạm bếp KDS khi khách tại bàn gửi đơn thành công.
- 📄 `qr-placeholder.png`: Hình ảnh mẫu mã QR phục vụ hiển thị fallback hoặc hướng dẫn quét mã.
