# Thư mục: src/features/

## 1. Mục đích
Tầng module hóa nghiệp vụ theo mô hình Feature-based (Bulletproof React). Mỗi thư mục con là một phân hệ độc lập.

## 2. Danh sách các module nghiệp vụ:
- `auth/`: Xác thực tài khoản quản trị/nhân viên.
- `menu/`: Thực đơn, danh mục và chi tiết món.
- `cart/`: Giỏ hàng dùng chung thời gian thực (Collaborative Cart).
- `orders/`: Lịch sử gọi món và tiến độ phục vụ.
- `kitchen/`: Trạm bếp KDS theo chuẩn FIFO.
- `tables/`: Sơ đồ bàn và mã QR động.
- `payment/`: Thanh toán tiền mặt và VietQR Napas247.
