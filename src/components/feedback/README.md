# Thư mục: src/components/feedback/

## 1. Mục đích
Chứa các thành phần phản hồi trạng thái hệ thống tới người dùng.

## 2. Danh sách các file JSX cần có:

### 📄 `Toast.jsx`
- **Mục đích:** Thông báo nổi góc màn hình báo thành công (Success), cảnh báo (Warning), hoặc lỗi (Error) (ví dụ: "Đã thêm món vào giỏ", "Nhân viên đang tới bàn của bạn").

### 📄 `ErrorBoundary.jsx`
- **Mục đích:** Bắt các lỗi runtime JavaScript trong component tree, hiển thị giao diện fallback thân thiện thay vì làm trắng toàn bộ trang.
