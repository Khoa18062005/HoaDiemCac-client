# Thư mục: src/pages/auth/

## 1. Mục đích
Chứa trang xác thực người dùng nội bộ cho toàn bộ hệ thống nhà hàng Hỏa Diệm Các.

## 2. Danh sách các file JSX:
- 📄 `LoginPage.jsx`: Màn hình đăng nhập hoàng gia sang trọng (Đen - Đỏ Đế Vương - Vàng Kim) dành cho Quản trị viên và Nhân viên (Thu ngân, Bếp trưởng KDS, Phục vụ). Tích hợp bộ chọn tài khoản demo nhanh cho 4 vai trò, kiểm tra hợp lệ thông tin, ghi nhớ phiên đăng nhập và điều hướng bảo mật.
