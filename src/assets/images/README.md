# Thư mục: src/assets/images/

## 1. Mục đích
Chứa các hình ảnh tĩnh được import vào các component JSX để Vite tối ưu hóa, nén ảnh và tự động gắn hash URL khi build.

## 2. Danh sách hình ảnh dự kiến:
- 📄 `hero-banner.jpg`: Ảnh banner ẩm thực bắt mắt trên đầu trang thực đơn của khách.
- 📄 `vietqr-logo.png`: Logo chính thức của chuẩn thanh toán VietQR Napas247.
- 📄 `empty-cart.svg`: Hình minh họa giỏ hàng rỗng khi khách chưa chọn món.
- 📄 `chef-cooking.svg`: Hình minh họa đầu bếp đang chế biến cho trang trạng thái món ăn.
