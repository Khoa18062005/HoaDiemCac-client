# Thư mục: src/features/menu/components/

## Danh sách các file JSX cần có:
- 📄 `CategoryTabs.jsx`: Thanh cuộn ngang các danh mục món (Lẩu, Nướng, Hải sản, Tráng miệng, Đồ uống...).
- 📄 `FoodCard.jsx`: Thẻ hiển thị món ăn gồm ảnh, tên, giá tiền VND, nút thêm/bớt số lượng.
- 📄 `FoodDetailModal.jsx`: Hộp thoại xem chi tiết mô tả món và ghi chú khẩu vị/dị ứng.
