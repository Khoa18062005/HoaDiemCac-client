# Thư mục: src/features/cart/components/

## Danh sách các file JSX cần có:
- 📄 `CartItem.jsx`: Dòng hiển thị từng món trong giỏ kèm bộ tăng giảm số lượng ($1 \le N \le 99$) và nút xóa.
- 📄 `CartDrawer.jsx`: Ngăn kéo trượt từ dưới lên (Bottom Sheet) hiển thị danh sách món đã chọn và tổng tiền tạm tính.
- 📄 `CartFloatingButton.jsx`: Nút tròn nổi góc dưới màn hình hiển thị tổng số món và tổng tiền.
