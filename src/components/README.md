# Thư mục: src/components/

## 1. Mục đích
Chứa toàn bộ các thành phần giao diện dùng chung (Shared UI, Navigation, Feedback) trên toàn ứng dụng.

## 2. Thư mục con:
- `ui/`: Các thành phần câm cơ bản (Button, Input, Modal, Badge, Spinner, Card).
- `navigation/`: Các thanh điều hướng (CustomerHeader, KitchenHeader, AdminHeader, AdminSidebar).
- `feedback/`: Các thành phần thông báo trạng thái (Toast, ErrorBoundary).
