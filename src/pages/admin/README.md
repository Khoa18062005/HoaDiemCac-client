# Thư mục: src/pages/admin/ (Màn hình Quản Trị)

## 1. Mục đích
Chứa các trang chức năng dành cho ban quản lý nhà hàng.

## 2. Danh sách các file JSX cần có:
- 📄 `DashboardPage.jsx`: Trang tổng quan hiển thị biểu đồ doanh thu theo ngày/tháng, số lượng đơn hoàn thành, top 5 món bán chạy nhất.
- 📄 `TableManagePage.jsx`: Trang quản lý sơ đồ bàn, tình trạng bàn, tạo mới hoặc cấp lại mã QR phiên bàn khi cần.
- 📄 `MenuManagePage.jsx`: Trang quản lý danh mục và món ăn (thêm mới, chỉnh sửa giá bán, cập nhật ảnh, bật/tắt trạng thái hết hàng).
