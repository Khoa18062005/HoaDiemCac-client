# Module: src/features/customer/ (Trải Nghiệm Khách Hàng Gọi Món Di Động)

## 1. Mục đích
Cung cấp toàn bộ các thành phần giao diện và dữ liệu phục vụ màn hình khách hàng quét mã QR tại bàn (Customer Mobile Flex Page), thiết kế theo phong cách vương triều tân cổ điển (Imperial Cyber-Banquet).

## 2. Cấu trúc thư mục:
- 📁 `components/`: Các UI components trực quan (Header, Collaborative Banner, Category Sidebar, Dish Card, Bottom Cart Bar, Cart Drawer).
- 📁 `data/`: Dữ liệu thực đơn mẫu phong phú (`mockCustomerMenu.js`).
- 📄 `index.js`: Điểm xuất nhập khẩu tập trung (Barrel export) cho toàn module.
- 📄 `README.md`: Tài liệu hướng dẫn module.
