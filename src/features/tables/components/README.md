# Thư mục: src/features/tables/components/

## Danh sách các file JSX cần có:
- 📄 `TableGrid.jsx`: Sơ đồ trực quan các bàn theo 3 trạng thái màu sắc: Trống (Xanh lá), Đang có khách (Đỏ), Đang dọn dẹp (Vàng).
- 📄 `QrCodeModal.jsx`: Hộp thoại tạo và tải ảnh mã QR chứa Dynamic Session Token (UUID v4 + băm) dán tại bàn.
